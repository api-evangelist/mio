# Mio

> Mio is a collaboration interoperability platform that connects the leading enterprise messaging tools — Google Chat, Microsoft Teams, Slack, and Zoom Team Chat — so teams on different platforms can work together without switching apps. Positioned as Google's official interoperability partner, Mio provides API-based middleware that relays messages, files, and directory information between platforms. It runs as native middleware built directly with the platform vendors, never persistently stores user messages or files, encrypts data in transit (TLS 1.2+) and at rest (AES-256), and holds SOC 2 Type II certification with GDPR and CCPA controls. Mio is sold as an enterprise offering rather than a self-serve public developer API.

## Products

- [Chat Sync](https://www.m.io/): Cross-platform messaging between Google Chat, Microsoft Teams, Slack, and Zoom Team Chat.
- [External Chat Sync](https://www.m.io/): Partner / federated collaboration across organizations.
- [Directory Sync](https://www.m.io/): Bidirectional user directory synchronization.
- [File Sync](https://www.m.io/): Shared Google Drive and SharePoint links across platforms.
